# Yemen Hypertension Screening 🇾🇪

## Overview
This project explores the use of Machine Learning to identify adults who may be at risk of elevated blood pressure, with the long-term goal of supporting early screening and preventive healthcare in Yemen.

## Objectives
- Explore publicly available health datasets.
- Identify potential risk factors associated with elevated blood pressure.
- Develop and evaluate machine learning classification models.
- Investigate the potential applicability of these models to the Yemeni population.

## Dataset
Dataset selection and exploration are currently in progress.

## Project Status
 Early development — Data collection and exploration.

## Disclaimer
This is an educational and research project. It is not intended to diagnose hypertension or replace professional medical evaluation.
